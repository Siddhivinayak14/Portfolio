## 🚀 How to Run Locally

### Option 1: Direct File Open
Simply double-click `index.html` or drag it into any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Python / Node / VS Code Live Server)
From the project folder in PowerShell / Terminal:
```bash
# Using Python 3
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.

---

## 🌐 How to Deploy to GitHub Pages (Free Hosting)

1. Create a new repository on your GitHub account (e.g. `portfolio` or `Siddhivinayak14.github.io`).
2. Push the files in this directory to your repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Siddhivinayak Mishra portfolio"
   git branch -M main
   git remote add origin https://github.com/Siddhivinayak14/<repo-name>.git
   git push -u origin main
   ```
3. Go to **Repository Settings** > **Pages** > Select `main` branch / `root` directory > Click **Save**.
4. Your site will be live within seconds!
